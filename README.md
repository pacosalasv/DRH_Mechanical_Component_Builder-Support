## Where this stands

Built to v1.0.0, development paused. The user manual and changelog are already in this repository, so you can read exactly what it covers. There is no public download while it's on hold.

<img src="docs/media/ScreenShot_01.png" alt="Mechanical Component Builder panel" width="100%" />

## What it does

Procedural, editable bolts, screws, nuts, washers, springs, rivets, studs, rings, and cutters. Hardware stays parametric, so a change in thread length or head style is a value, not a remodel.

## Who it's for

Hard-surface artists adding believable hardware to a model. Game and prop artists kitbashing machinery. Vehicle modelers who need visible fasteners that survive a close-up.

## Why it's paused

The released add-ons get the maintenance pass first. This one has the widest parameter surface of the paused tools, which means the most compatibility work before a release I'd stand behind.

[Open an issue](https://github.com/pacosalasv/DRH_Mechanical_Component_Builder-Support/issues) if you need it. Tell me the component you'd use most; that decides what gets verified first.
